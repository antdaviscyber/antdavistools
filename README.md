# Tools

Free, vendor-neutral tools built for security awareness and human risk practitioners, plus a few general-purpose utilities. No login. No data collection. No vendor agenda.

Live at [tools.antdavis.com](https://tools.antdavis.com).

Built and maintained by [Ant Davis](https://antdavis.com).

---

## Live tools

| Tool | Description | URL |
|------|-------------|-----|
| Analog Toy | Gives your photos a toy camera film look, right in the browser. A rebuild of a much-loved photo app that stopped being supported. | [Open tool](https://tools.antdavis.com/analogtoy/) |
| World Time Thing | A time zone converter for working out what time it is everywhere that matters. | [Open tool](https://tools.antdavis.com/worldtimething/) |
| PosterPrompt | A poster prompt generator built to get past generic AI poster output and into prompts with actual style. | [Open tool](https://tools.antdavis.com/posterprompt/) |
| FrameGrab | Pulls clean still frames out of video, in the browser. | [Open tool](https://tools.antdavis.com/FrameGrab/) |
| AnyPNG | Converts HEIC and other image formats to PNG, in the browser. | [Open tool](https://tools.antdavis.com/AnyPNG/) |
| Audio Convert | Converts m4a, aac, wav, ogg and flac to MP3 or WAV, on your own machine. | [Open tool](https://tools.antdavis.com/audio-convert/) |
| Capacity Visualisation Calculator | Model your current time allocation and show how it changes with new headcount, whether you run the programme solo or as a team. | [Open tool](https://tools.antdavis.com/capacity-calculator/) |

Also on the tools hub but not part of this repo: [ExtRenew](https://extrenew.com), a recurring 30-day permissions checkup for Chrome and Firefox extensions.

## About

These tools exist because the security awareness and human risk space is full of vendor-produced resources with strings attached. These tools have none. They run entirely in the browser, store nothing, and are free to use and share.

Each tool lives in its own folder as a self-contained page. No frameworks, no build pipeline, no dependencies to manage beyond what's loaded from CDN where noted.
